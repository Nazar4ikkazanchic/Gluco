# Gluco 🩸

Програма для iPhone (iOS 17+), яка показує цукор із Nightscout: головний екран із графіком, записи інсуліну/вуглеводів/нотаток, статистика, віджети та кнопка «Надіслати батькам» через Telegram-бота.

## Як це збирається

Mac не потрібен. При кожному оновленні коду GitHub сам збирає програму на хмарному Mac
(вкладка **Actions** → останній запуск → **Artifacts** → `Gluco-ipa`).

## Встановлення на iPhone

Файл `Gluco.ipa` ставиться через SideStore з безкоштовним Apple ID (оновлення раз на 7 днів).

## Налаштування в програмі

1. **Nightscout**: адреса сайту + токен із роллю `readable` (Admin Tools → Subjects).
2. **Telegram**: токен бота від @BotFather → батьки пишуть боту `/start` → «Знайти чати».

> Gluco не є медичним виробом. Рішення щодо інсуліну приймай за глюкометром/сенсором і порадами лікаря.
